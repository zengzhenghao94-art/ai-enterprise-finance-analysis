## 三、演示流程（推荐）

> 按这个顺序走，约 4 分钟。每个步骤标了 ⭐ 重要度，时间不够就只走 ⭐⭐⭐。

### 步骤 1：整体仪表盘（30 秒）⭐⭐⭐

**做什么：** 什么都不用点，打开页面就是。

**指给评委看：**
1. 6 张 KPI 卡片——收入、成本、净利润、运营费用、经营现金流、应收账款
2. 月份趋势折线图——X 轴是月份，三条线（收入、成本、净利润）
3. 异常预警——红色/橙色标记的异常指标

**说：**
> "这是我们的经营分析驾驶舱。左侧是 KPI 总览和趋势图表，右侧是 AI 智能问数和自动简报生成。所有数据都是实时从数据库查询的。"

**切换一下年份和部门**（证明数据是动态的）：
1. 年份从 2025 切到 2024 → KPI 数字变了、图表变了
2. 部门从"全公司"切到"销售部" → 数据变成销售部的

---

### 步骤 2：异常检测（40 秒）⭐⭐⭐

**做什么：** 滚动到「异常预警」区域。

**指给评委看：**
1. 异常卡片有颜色分级——🔴 高风险（红底）、🟠 中风险（橙底）
2. 每条异常显示：指标名称、部门、年月、实际值 vs 预期范围、偏离百分比
3. 鼠标悬停在偏离百分比上 → 显示 tooltip 解释

**说：**
> "这是我们用 Isolation Forest 算法做的异常检测。它在 6 个经营指标维度上自动发现偏离正常模式的数据点。比如这条——毛利率偏离预期 19.9%，系统自动标记为高风险。传统方式下财务人员要月底做报表时才能发现，现在数据产生就能预警。"

**可选操作：** 点击「重新检测」按钮 → 触发 ML 模型重新跑一遍（演示系统确实在跑算法）。

---

### 步骤 3：智能问数（60 秒）⭐⭐⭐

**做什么：** 点击右侧「智能问数」面板里的示例问题。

**推荐演示顺序：**

**3a. 先点一个查数示例**（如"全公司 2025 年总收入是多少？"）
- 等待 2-3 秒 → 出现三块内容：
  1. 📝 生成的 SQL（深色代码块）
  2. 📊 查询结果表格
  3. 💡 AI 的自然语言解读

**指给评委看 SQL 代码块：**
> "用户输入自然语言，AI 自动翻译成 SQL。这个 SQL 是从 LLM 实时生成的，不是预设模板——评委可以现场输入任意问题验证。"

**3b. 再点一个分析示例**（如"各部门 2025 年 6 月的毛利率排名"）
- 结果出来后有追问建议按钮 → 点一个追问 → 证明支持连续对话

**3c. 手动输入一个自定义问题**（证明不是预设）：
- 比如输入："销售部和生产部的现金流哪个更健康？"
- 或者："2024 年到 2025 年哪个部门增长最快？"

**说：**
> "传统方式下管理层想查一个数，要打电话给财务部 → 财务人员打开 ERP 导出数据 → Excel 做透视表 → 至少 20 分钟。现在输入一句话，5 秒出结果。查询效率提升 240 倍。"

**⚠️ 注意：** LLM 生成 SQL 偶尔可能不准（80%+ 准确率），如果结果不对：
- 换一个更简单的问法重试
- 看 SQL 代码块——SQL 本身对不对？如果 SQL 对但数据不对，可能是问法有歧义
- 备选安全问法见 [兜底方案](#五兜底方案)

---

### 步骤 4：经营简报（30 秒）⭐⭐

**做什么：** 点击「经营简报」面板的「生成简报」按钮。

**等待 5-10 秒** → 生成一份 Markdown 格式的简报，包含：
- 📋 简报标题
- 🔑 关键发现列表
- 📝 四段式正文（总体概况 → 分部门分析 → 异常预警 → 行动建议）

**操作：**
1. 滚动简报内容 → 展示完整结构
2. 切换月份 → 再生成一份 → 证明内容随数据变化
3. **点「导出」按钮** → 浏览器下载 ZIP 文件 → 解压打开 HTML（可选）

**说：**
> "传统方式下写一份月度经营分析报告需要 2-3 天——收集数据、做表、写分析、排版。现在 AI 3 秒生成 Markdown 初稿，财务人员只需要审核和补充。从 3 天到 3 秒。而且我们支持一键导出——ZIP 包里包含 HTML 报告、4 张高清图表 PNG 和独立的 CSS 样式文件，可以直接打印或邮件发送给管理层。"

---

### 步骤 5：展示 AI vs 传统对比（20 秒）⭐⭐

**做什么：** 口头总结，不需要操作。

**说：**
> "总结一下，三个 AI 角色各司其职：Isolation Forest 做异常哨兵——从滞后 2-4 周到实时预警；通义千问做数据翻译官——从 20 分钟到 5 秒查数；同一个模型做报告写手——从 3 天到 3 秒生成简报。这不是用 AI 包装传统流程，而是从根本上改变了经营分析的工作方式。"

## 四、三个 AI 能力逐个演示

> 如果评委说"挑一个重点讲讲"，用下面这个。

### 🛡️ 数据哨兵 — 异常检测

| 操作 | 预期结果 |
|------|---------|
| 页面默认加载 | 异常预警区域显示 3-5 条异常卡片 |
| 切换部门到"销售部" | 只显示销售部的异常 |
| 切换年份到 2024 | 只显示 2024 年的异常 |
| 点击「重新检测」 | 按钮变灰 + 转圈 → 提示"检测中" → 完成后刷新列表 |
| 鼠标悬停偏离百分比 | Tooltip 显示"实际值偏离预期均值 高/低 X%" |

**技术点（评委可能问）：**
- 算法：Isolation Forest（隔离森林），无监督学习，不需要标注异常样本
- 原理：异常点更容易被随机分割隔离→在树中路径更短
- 为什么不用规则（如"毛利率<20%报警"）：不同部门、不同月份的"正常"范围不一样——销售部毛利高、生产部成本高。规则要每个部门单独设定阈值，ML 自动从数据分布中学。

---

### 🌉 数据翻译官 — NL2SQL

| 操作 | 预期结果 |
|------|---------|
| 页面加载 | 示例问题随部门/年份动态变化 |
| 点击查数示例 | 2-3 秒后显示 SQL + 表格 + 解读 |
| 点击分析示例 | 同上，但问题是分析型的（排名/趋势/对比） |
| 手动输入自定义问题 | 输入框 + Enter 或点发送 |
| 结果出来后点追问按钮 | 自动填入问题并发送 |
| 切换到"生产部"再看示例 | 示例问题自动从"全公司"变成"生产部"相关 |

**安全问法（100% 能跑通的）**：
- "销售部 2025 年 6 月的收入是多少？"
- "全公司 2025 年上半年净利润"
- "各部门 2025 年 6 月毛利率排名"
- "生产部 2025 年各月收入"

**技术点（评委可能问）：**
- NL2SQL 流程：用户输入 → LLM 理解意图 + 查表 Schema → 生成 SQL → 安全校验（SELECT-only + 关键字白名单）→ 执行 → LLM 解释结果
- 为什么不用模板匹配：模板只能覆盖预设问题，用户问法千变万化。"毛利率最高的部门"和"哪个部门赚钱能力最强"是同一个意思——靠模板匹配不到，靠 LLM 能理解。

---

### 📝 报告写手 — 自动简报

| 操作 | 预期结果 |
|------|---------|
| 选择月份（默认当前月），点击「生成简报」 | 5-10 秒后显示 Markdown 简报 |
| 切换部门到"销售部"再生成 | 简报聚焦销售部，标题自动变成"销售部" |
| 切换到"全公司"再生成 | 简报包含三个部门的逐部门分析 + 横向对比 |
| 切换月份到 3 月再生成 | 简报变成 3 月的数据分析 |
| 切换年份到 2024 再生成 | 简报变成 2024 年（年份标签与右上角同步） |
| 点「导出」按钮 | 浏览器下载 ZIP 文件 → 解压得 HTML + 4 张图表 PNG + CSS |

**技术点（评委可能问）：**
- AI 看了什么数据：当前筛选条件下的经营指标数据 + 异常检测结果 + 历史同期对比
- 为什么 AI 生成的报告比人写的更一致：Prompt 模板保证结构统一（四段式），每次都覆盖总体、分部门、异常、建议
- AI 会不会瞎编数据：不会。数据来自 SQLite 实际查询结果，LLM 只是对真实数据做总结和分析。
- **导出原理**：后端用 matplotlib（200 DPI）渲染 4 张图表 PNG → 组装 HTML → ZIP 打包 → 浏览器触发下载。图表不入 HTML（外引），保持报告文件干净、可打印。

## 五、兜底方案

### 问题 1：后端启动失败

**症状：** 前端页面空白，Console 有网络错误

**排查：**
```bash
# 1. 确认后端进程在不在
curl http://127.0.0.1:8000/api/health

# 2. 如果报 connection refused，重启后端
# 3. 如果报 proxy error，检查代理环境变量
echo $HTTP_PROXY    # 如果输出不是空的，执行下面的
unset HTTP_PROXY HTTPS_PROXY http_proxy https_proxy
```

### 问题 2：前端页面空白

**排查：**
```bash
# 确认前端在跑
curl http://localhost:5173

# 如果 5173 不通，重启前端
cd D:/ai企业赋能财务分析/frontend && npm run dev
```

### 问题 3：NL2SQL 查询失败

**症状：** 问了一个问题，返回错误或空结果

**处理：**
1. 不要慌，自然地说："这个问题问法有点歧义，我换一种问法"
2. 用这些**已验证的问法**：
   - "销售部 2025 年 6 月收入"
   - "各部门 2025 年上半年净利润"
   - "全公司毛利率排名"
3. 切到 2025 年（LLM 对 2025 的训练数据更熟，这个概率因素存在）

### 问题 4：简报生成超时

**症状：** 点了「生成简报」，一直转圈

**处理：**
1. 等 15 秒，LLM API 偶尔慢
2. 超过 15 秒 → 刷新页面 → 重新生成
3. 还不行 → "AI API 响应比较慢，我们可以先看其他功能，稍后再展示简报生成"

### 问题 5：异常检测显示为空

**症状：** 异常预警区域显示"未检测到异常"的绿色对勾

**处理：**
1. 确认在"全公司"+ 2025 年（种子异常在 2025 年）
2. 点「重新检测」→ 触发 ML 检测
3. 还不行 → 切换到 2024 年（2024 年也有 2 条种子异常）

### 终极兜底：刷新大法

```
F5 刷新页面 → 所有状态回到初始值（全公司 + 2025）
```
