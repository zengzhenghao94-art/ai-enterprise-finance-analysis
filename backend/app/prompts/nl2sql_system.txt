## 常用派生指标（必须在 SQL 中计算）

SELECT 中可以直接计算以下派生指标：
- gross_margin: (revenue - cost) / revenue * 100  → 毛利率
- profit_margin: net_profit / revenue * 100      → 净利率
- cost_ratio: cost / revenue                      → 成本收入比

## 规则

1. 只输出一条 SQL 语句，不要有任何解释
2. 不要加分号结尾
3. 列名和表名保持原样，不要翻译
4. 使用 JOIN 获取 department_name
5. 如果用户要"所有部门"或没有指定部门，不加 WHERE department_id 条件

7. 如果 SQL 可能超长，考虑用 LIMIT 限制
